Mastery / Ability Point Budget — three paths compared

The current 20-cap mastery is reached at player ~35, not 100. Three ways to fix it: patch the 20-cap, extend to 60, or align 1:1 with the char-level cap (100).

The diagnosis SCALES MISMATCHED

Today: mastery 20 is reached at approximately player level 30–40, not 100.

Cumulative mastery XP to hit mastery 20 = ~68,000.
Cumulative mastery XP a focused player earns reaching player level 100 (at-level grinding) ≈ 2–5 million.

Recommendation

Path C — 100-cap, 1:1 char alignment, build complete by mastery 70.

Versus Path B:

  • One bar matches the other. Mastery 100 = char 100 visually. Player intuition: "this is the same journey."
  • Grant frequency stays high (~1 per char level) but ends mid-game. Build choices concentrate in the early-mid where they matter most.
  • Last 30 levels reframe as stat-grind endgame. Not "nothing happening" — mastery 71→100 is still +43% discipline stat bonus. Different KIND of reward.
  • Variable grant rate (2→1→0) creates an arc. Not monotone like B. The "1 pt phase" feels like the "finishing touches" stage.

Implementation:

  1. MASTERY_CAP = 100 in weapon_mastery.gd.
  2. Replace const ABILITY_POINTS_PER_MASTERY_LEVEL with a function: 
    static func points_granted_at_mastery(level: int) -> int:
    if level <= 50: return 2
    if level <= 70: return 1
    return 0
  3. Update reconcile_ability_points() granted-sum to use a cumulative-points helper (sum the function over [1, mastery_level]).
  4. Calibrate XP_BASE / XP_LINEAR / XP_QUADRATIC / XP_CUBIC so mastery N's cumulative XP roughly tracks char N's cumulative XP. First-pass: 30 + 30N + 5N² + 0.1N³ — tune in playtest.
  5. Existing saves: chars currently at mastery ≤20 get a refund for the granted-vs-spent delta (the new function grants 2/lvl from rank 1 vs old 6/lvl). Show a one-time "your mastery scale was rebalanced; you have X unspent points" notice.

Caveat The 50/70 tier boundaries and the XP curve coefficients are first-pass. Playtest L1–L30 first; if 2 pts/level feels too slow early, bump to 3 pts/level for the first 20-30 mastery ranks (and shorten the 1-pt tier accordingly to keep 120 total).

All numbers derived from current curve resources + memory invariants. Tier boundaries and XP coefficients are tunable.
