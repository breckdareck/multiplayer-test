Upgrade & Passive Audit

Weapon-identity overhaul — do all 340 upgrades and 28 passives actually do something meaningful?

SummarySwordBow StaffDaggerPassives

Executive summary

Audited all 347 upgrades across 80 abilities and 28 passives. Method: every upgrade's effect_key is matched to its real consumer call-site in code, and each handler was read to confirm the magnitude is actually applied and meaningful (not read-and-ignored).

☑ The system is overwhelmingly healthy. All 86 unique effect_keys are consumed in code — zero dead keys, zero zero-magnitude upgrades. The generic handlers (bonus_damage_mult, bonus_targets, bonus_hits, bonus_lifesteal, cooldown/mana_flat_reduction, passive_stat_flat/percent_bonus, conditional_damage_bonus) all apply correctly; all 14 stat passives reach the player's stats; and the conditional-damage + proc dispatch pathways are wired end-to-end. The only functional bug found is now fixed.

Investigated & confirmed NOT bugs

Two findings raised during the audit were verified against the actual code and are working correctly — listed so they aren't re-chased:

  • Overload / Killing Spree / Opportunist / Toxicology / Composure upgrade tiers — Verified WORKING via ability.gd:420-421 — the generic conditional_damage_bonus path adds each upgrade's magnitude when the passive's condition fires, regardless of _level_bonus().
  • Mark of the Hunt — Bleeding Mark (T3) — Verified WORKING: combat.dot_scaling_base() defaults dmg_pct to 100 for damage-less abilities (combat.gd:1195-1199), so the bleed = max_range × 0.05 — fully stat-scaled, not 1 HP.
